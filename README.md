# Северный рейд — оригинальная мобильная 3D-игра

Оригинальный прототип extraction-игры на Godot 4. Исследуй заброшенную станцию, собирай припасы и эвакуируйся. Это самостоятельный проект без игровых ресурсов, названий, карт или интерфейса PUBG/Metro Royale.

## Режимы

- **Офлайн:** одиночный прототип запускается без интернета; сетевую комнату создавать не нужно.
- **Локальная сеть (прототип):** открой кнопку «ЛОКАЛЬНАЯ СЕТЬ». На одном телефоне нажми «Создать», а на другом в той же Wi-Fi сети введи локальный IP первого телефона и нажми «Подключиться». Порт — UDP 2456. Для поиска IP обычно открой сведения о подключённой Wi-Fi сети на телефоне-хосте.
- В сетевом прототипе синхронизируются подключения и позиции простых аватаров. Игровые действия, добыча, инвентарь, стрельба, эвакуация, чат и административные команды пока не синхронизированы между устройствами.

## Уже реализовано

- процедурная 3D-локация, укрытия и камера от третьего лица;
- сенсорные кнопки перемещения и действий;
- подбор нескольких видов добычи и точка эвакуации;
- тренировочные цели не атакуют игрока;
- тестовая админ-панель, дрон-сканер и быстрая эвакуация.

## Важно про администратора

Ник `KillerKC2` и текущие кнопки админ-панели — демонстрационная локальная заглушка, а не защищённая система входа или реальные сетевые баны/муты. В сетевой игре нельзя доверять ни нику, ни клиентскому коду для выдачи прав: перед настоящим мультиплеером потребуется авторитетный хост/сервер, который проверяет роль и выполняет команды. Сейчас админ-действия не распространяются на другие устройства.

## Запуск и экспорт

1. Установи Godot 4.3 или новее и открой папку с `project.godot`.
2. Запусти проект клавишей F6/F5.
3. Для Android настрой Android SDK и шаблоны экспорта в Godot, затем используй **Project → Export → Android**. Проверь Android-разрешение `INTERNET` в настройках экспорта для сетевого режима.

Сборка/запуск проекта здесь не выполнялись. Это ранний прототип: нет готового APK, полноценной синхронизации матча, постоянных аккаунтов и серверной проверки админских прав.
