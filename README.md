# Северный рейд — оригинальная мобильная 3D-игра

Оригинальный прототип extraction-игры на Godot 4. Игрок исследует заброшенную северную станцию, собирает припасы и пытается эвакуироваться. Это самостоятельный проект: без названий, карт, интерфейса и материалов PUBG/Metro Royale.

## Что уже есть

- 3D-локация с укрытиями и камерой от третьего лица;
- сенсорные кнопки движения и кнопки действий;
- подбор трёх видов добычи с разной условной ценностью;
- точка эвакуации и проверка успешного завершения вылазки;
- неподвижные тренировочные мишени, которые не атакуют игрока и не наносят урон;
- управление на компьютере клавишами WASD или стрелками.

## Запуск

1. Установи Godot 4.3 или новее.
2. Открой в Godot папку проекта с файлом `project.godot`.
3. Запусти проект клавишей F6/F5. На телефоне экспортируй проект через **Project → Export → Android** после установки Android SDK и шаблонов экспорта.

## Ограничения

Это одиночный прототип. В нём нет сетевой игры, настоящих пользовательских аккаунтов, чата или административной панели. Админ-команды вроде бана, мута и выдачи предметов возможны только после разработки сетевого сервера и проверки прав на серверной стороне; одного игрового ника для этого недостаточно. Также пока нет готового APK. Сборка и запуск проекта в этой среде не проверялись.
