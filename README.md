# Северный рейд — Android 3D prototype

Небольшой оригинальный 3D-прототип extraction-шутера для Godot 4: вылазка на заброшенную северную станцию, сбор припасов и эвакуация. Это самостоятельный учебный проект, а не копия PUBG Mobile/Metro Royale; использованы только процедурные примитивы, без чужих ассетов и названий.

## Особенности прототипа

- простая 3D-локация, укр��тия, камера от третьего лица;
- сенсорные кнопки движения, стрельбы, подбора и эвакуации;
- мишени можно сбивать попаданием по центру экрана;
- золотые предметы собираются рядом с игроком;
- для победы нужно принести хотя бы один предмет к зелёной точке;
- комфортный режим: мишени не атакуют игрока и не наносят урон.

## Запуск

1. Установи Godot 4.3 или новее.
2. Открой в Godot папку репозитория (файл `project.godot`).
3. Запусти проект клавишей F6/F5. На компьютере можно передвигаться стрелками/WASD; на телефоне кнопки отображаются в интерфейсе.
4. Для Android установи Android export templates и SDK в Godot, затем выбери **Project → Export → Android**.

Это игровой прототип: здесь пока нет сетевой игры, полноценной системы оружия/инвентаря, анимаций, сохранений и оптимизации под конкретные устройства. Экспорт и запуск в редакторе в этой среде не проверялись.
