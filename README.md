# Мой AI-чат для Android

Стартовый Android-клиент на Kotlin и Jetpack Compose. Он отправляет сообщения на **указанный тобой HTTPS-сервер** и показывает его ответы.

## Важно

- Это не официальный клиент GitHub Copilot или ChatGPT и не подключается к твоему аккаунту Copilot/ChatGPT.
- Для работы нужен серверный API, к которому у тебя есть законный доступ. Приложение не обходит региональные ограничения или правила сервиса.
- В приложении нет доступа к функциям телефона (файлам, микрофону, геолокации и т. п.). Оно только отправляет текст, который ты сам вводишь.
- Не встраивай секретный API-ключ в APK: его можно извлечь. Храни секреты на сервере и используй авторизацию/ограничение запросов.

## Контракт API

Приложение отправляет `POST` с `Content-Type: application/json`:

```json
{"message":"Привет"}
```

Сервер должен отвечать JSON-объектом с непустым полем `reply`:

```json
{"reply":"Привет! Чем помочь?"}
```

## Запуск

Открой репозиторий в Android Studio с установленными Android SDK 35 и JDK 17. Собери и запусти конфигурацию `app` на эмуляторе или устройстве. В приложении укажи HTTPS URL API. Для полноценной интеграции следующим шагом нужно развернуть серверную часть, которая обращается к выбранной модели через официальный поддерживаемый API.
